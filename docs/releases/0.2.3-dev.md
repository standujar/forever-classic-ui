# 0.2.3-dev — Classic UI options in Edit Mode

- Moves the Classic UI master switch, module checkboxes, statuses and reset
  directly into the native Edit Mode window. The options follow that window's
  visibility and movement; there is no separate addon Settings category.
- Opens Edit Mode with `/foreverui` or `/foreverui edit`. The existing
  `/foreverui settings` subcommand remains an alias. The options also appear
  when opening **Escape → Edit Mode**.
- Keeps existing `ForeverReframedDB` choices. Changes apply immediately across
  all layouts; native Edit Mode **Save** and **Revert** do not undo addon choices.
- Retains the three experimental side-and-bottom window-border modules for
  quests, talents/spellbook and the world map. Fresh settings default to off.
- Keeps nameplates native. Unit frames, complete Classic windows and the
  remaining HUD are still future work.

The package targets Forever beta `1.60.1.69893` with candidate Interface `16001`.
The border modules retain their exact-build and frame-shape checks. Opening the
options requires native Edit Mode to be available and allowed outside combat;
restoration changes defer during combat. Actual beta rendering, interactions,
layout behavior and compatibility remain unverified.
