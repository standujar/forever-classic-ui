# 0.3.0-dev — Grouped controls and more Classic window borders

- Adds **Classic everywhere** and **Restore Forever** to the Classic UI section
  in native Edit Mode. Select groups instead of checking every window.
- Organizes choices into **Unit frames**, **Windows**, **Maps**, and **Action bars
  & HUD**. Groups without implemented modules display **Coming soon**.
- Adds collapsed **Customize** lists for individual exceptions and a mixed state
  for partially selected groups. Group defaults also apply to future modules;
  Classic everywhere opts into all groups, including future unit-frame/HUD work.
- Keeps failed styling or native-restoration status visible in group summaries,
  even when Customize is collapsed.
- Preserves existing `ForeverReframedDB` choices. Changes apply immediately across
  all layouts; native Edit Mode Save/Revert does not undo them. Restore Forever
  clears group defaults and exceptions and returns applied skins to native borders.
- Expands partial Classic side-and-bottom borders from three windows to sixteen:
  quests, talents/spellbook, world map, character/skills, professions, recipe
  inspection, merchants, mailbox, opened mail, friends/social, NPC conversations,
  trade, auction house, bank, trainers, and books/letters.
- Supports Forever beta **1.60.1 build 69913**, retaining build **69893** support.
  Interface **16001** is confirmed by the user's build 69913 logs.

These are partial border skins. Native titles, portraits, buttons, contents,
window sizes and layouts remain unchanged. Complete Classic windows, unit frames,
HUD, bags and loot skins remain in development. Nameplates stay native. The
separate local BlizzMove movement fixes are not included in this addon.

Fresh settings default to off. Unsupported, protected or forbidden frames retain
native appearance. Changes defer during combat. Offline checks pass: **47 Lua
addon tests and 21 Python release-tool tests**. In-game rendering, interactions,
combat and addon compatibility for this version still need validation.
