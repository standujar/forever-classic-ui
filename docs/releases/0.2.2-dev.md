# 0.2.2-dev — Classic UI - Forever Reframed

- Introduces the Classic UI - Forever Reframed name, the `ForeverReframed`
  addon folder and independent `ForeverReframedDB` settings.
- Uses `/foreverui` for native Settings, diagnostics and texture samples.
- Provides a master switch and per-module checkboxes, saved choices and reset.
- Includes experimental Classic side and bottom borders for quest interactions,
  the combined talents/spellbook window and the world map.
- Keeps nameplates native. Unit frames and the remaining HUD are future work.

This is an early development Release targeting Forever beta `1.60.1.69893`
with candidate Interface `16001`. The three border modules require that exact
build. They retain native top decoration, controls, contents and gameplay;
they do not restore complete Classic windows. Everything starts disabled.
Actual beta rendering, interactions and compatibility remain unverified.
